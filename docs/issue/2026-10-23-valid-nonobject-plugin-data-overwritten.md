# 合法 JSON 但不是对象的插件设置仍被静默覆盖

状态：未修复

> 来源：2026-10-21 修复交接中的额外发现，2026-10-23 复核；不计入原 54 条。
> 严重程度：中 · 置信度：代码路径已核对

## 问题与依据

`readPersistedData()` 对 `loadData()` 返回的 `[]`、`42`、字符串或 `null` 直接接受；`plugin/src/settings/load.ts` 的 `settingsAndStateFromPersistedData()` 将非普通对象替换为 `{}`，没有格式警告。插件按默认值启动，后续保存可以覆盖原文件。第二批 OBS-08 保护的是 JSON 解析失败，未覆盖合法但结构错误的文件。

## 建议和验收

区分文件不存在与文件存在但顶层无效；对后者沿用备份和提示流程。测试数组、数字、字符串、null，验证原文保留、用户收到提示；首次启动无文件仍正常。
