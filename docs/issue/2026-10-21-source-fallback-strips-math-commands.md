# 没有 HTML 版本的论文走 LaTeX 源码回退时，公式里的命令被整体删掉（±、≤、σ、\frac…），模型读到的是被破坏的数字

> 发现日期：2026-10-21 · 来源：main `d999037` 深度代码审查 · 编号 PIPE-04
> 范围：日报逐篇摘要和论文详细笔记（没有 arXiv HTML 渲染版、改用 e-print 源码的论文） · 严重程度：中 · 状态：未修复 · 置信度：已复现

## 问题

取论文正文时先用 arXiv 的 HTML 渲染版（公式经 `preserveMathText` 保留成 `$tex$`）；没有 HTML（新论文公布当天较常见，或转换失败）时改下载 e-print 源码包，用 `extractLatexSource` 把 LaTeX 转成纯文本，再交给模型写摘要和详细笔记。

这个转换把所有 `\命令` 一律删掉，包括 `$…$` 里面的数学命令，只留下 `$` 符号和参数残片。实测（一次性测试，已删除）：

| 源码里的 LaTeX | 模型读到的文本 |
| --- | --- |
| `$H_0 = 67.4 \pm 0.5$` | `$H_0 = 67.4 0.5$`（误差变成第二个数字） |
| `$z \sim 0.5$`、`$H_0 \approx 67$` | `$z 0.5$`、`$H_0 67$`（关系符号消失） |
| `$\Omega_m \leq 0.3$` | `$_m 0.3$`（上限变成无符号的 0.3，Ω 也没了） |
| `$4.2\sigma$` | `$4.2$`（显著性单位丢了） |
| `$\frac{1}{3}$` | `$13$`（三分之一变成十三） |
| `$\alpha = 0.31^{+0.04}_{-0.05}$` | `$ = 0.31^+0.04_-0.05$` |
| `95\%`、`\$5` | `95`、`5`（百分号、美元号丢了） |
| `Fig.~\ref{fig:a} and \citet{foo}` | `Fig. and .` |

摘要提示词要求“数值、单位、符号照原文复制”“区分上限和测量值”，但这些符号在源头已经没了。模型要么原样复述残缺的式子，要么凭常识猜（猜错就是错的数字或方向），而产出的摘要看起来完全正常，没有任何标记；摘要或笔记一旦写入就不会重跑。天文、高能、机器学习类论文的结果句大量依赖 `\pm`、`\leq`、`\sim`、`\sigma`、`\frac`，影响面不小。

## 原因

- `packages/core/src/pipeline/source-extractor.ts:384-408` `plainLatex`：第 393-400 行反复把 `\cmd{arg}` 换成 `arg`（`\frac{1}{3}` 变成 `1{3}`，后面删掉花括号得到 `13`）；第 402 行 `text.replace(/\\[A-Za-z]+\*?(?:\[[^\]]*\])?/g, "")` 删除所有剩余命令；第 403 行删除 `\%`、`\$`、`\_` 等转义；第 404 行删除花括号。整个过程不区分数学环境内外。
- `source-extractor.ts:343`、`:414-416`：`latexToMarkdown` 和 `extractAbstract` 都走这条路径，没有像 HTML 路径那样先保护数学片段。
- 对比 `packages/core/src/pipeline/section-extractor.ts:170-189` `preserveMathText`：HTML 路径把公式保留为 `$tex$`，两条路径的内容质量差很多，而提示词和后续校验只按“公式已保留”设计。
- 下游：`packages/core/src/pipeline/daily-paper-summary.ts:296-318`、`packages/core/src/pipeline/summarizer.ts:303-309` 把这些文本原样放进提示。

## 可能的解决方案

推荐：在 `plainLatex` 之前先把数学片段（`$…$`、`\(...\)`、`\[...\]`、`equation` 等行内/行间环境）整体摘出来保护，只对数学之外的文本去掉命令；数学内部保留原始 TeX（必要时只去掉 `\label`、`\nonumber` 这类排版命令）。转换后的文本里的 `$…$` 与 HTML 路径一致，后续的数学校验也能正常工作。

备选：源码回退时只把“正文字符串”交给模型，并在来源行里标明“公式已省略”，同时在提示词里告诉模型这份文本的数学符号不可信，涉及数值的字段写“原文未说明”。

## 修复后应补的测试

- `$H_0 = 67.4 \pm 0.5$`、`$\Omega_m \leq 0.3$`、`$\frac{1}{3}$`、`95\%` 经 `extractLatexSource` 后保持原样（或等价）。
- 数学环境之外的 `\cite`、`\ref`、`\textbf{…}` 仍被清理。
- 同一篇论文经 HTML 路径和源码路径，公式片段的 `$…$` 一致。
