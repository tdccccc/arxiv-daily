# 工作台（Workbench）

[arXiv Daily](https://github.com/tdccccc/arxiv-daily) 的本地浏览器阅读器——不需要 Obsidian。同一个阅读器也嵌入在 [DSH 插件](../extensions/dsh-arxiv-daily/README.md)的侧栏中。

## 打开方式

```bash
arxiv-daily ui
arxiv-daily ui --port 8123   # 使用固定端口
arxiv-daily ui --no-open     # 只打印地址，不自动打开浏览器
```

无论是否已有配置都可以运行，只在 `127.0.0.1` 上提供服务，按 Ctrl+C 停止。

## 首次使用

还没有配置时，会自动打开设置页：输出目录、模型 API key、arXiv 分类、研究主题。自动生成日报在完成首份报告前都是可选的。

## 浏览

- 左侧是可调宽度、可收起的侧栏（拖动分隔条或用方向键），放着**日历**和**搜索/主题/阅读状态筛选**；宽度和收起状态会保存下来。
- 右侧论文列表显示全部已索引的发现结果，包括还没有详细总结的论文，支持排序和分页。选中某个日期会按该日筛选；需要一个明确的操作才能打开完整日报。
- 点击论文显示已保存的概览和详细操作。日历格子按颜色显示当天论文数量。
- 正文、摘要支持 Markdown 表格、代码、图片，以及数学公式（`$…$` 和 `$$…$$`）。相对链接和不产生歧义的 Obsidian wikilink 可以在已有报告之间跳转；Source/PDF 按钮打开论文原文。
- 前进/后退在当前这次工作台会话的阅读历史内跳转（恢复筛选、锚点和滚动位置），重启后不保留历史。“返回列表”恢复列表的筛选、分页和滚动位置。“浏览 Markdown 文件”还能看到独立笔记。
- 日期使用你配置的时区；浏览本身不会判断 arXiv 当天是否已发布公告，也不会触发生成。
- 窄屏下通过专门的日历/筛选按钮打开侧栏内容。

## 阅读状态与收藏

每篇论文有阅读状态（未标记/待读/已读）和独立的收藏标记，都保存在共享的论文索引里。标记操作不会改写 Markdown 文件。

## 生成日报

点击**生成**会运行和 CLI 相同的日报/手动生成流程（包括配置好的邮件发送），显示进度并可以取消。其他日期会显示已保存的状态，有可用数据时还会提供日期预填的生成/重试表单。

四种结果会分别清晰显示：

| 状态 | 含义 |
|---|---|
| 等待公告 | 当天 arXiv 还没有发布该分类的公告；不计入失败重试次数 |
| 当日无更新 | 已确认当天该分类没有新论文 |
| 无匹配 | 筛选已完成，但没有论文匹配你的研究主题 |
| 失败 | 真正的失败 |

页脚显示输入/输出/总 token 数、生成耗时和生成时间（UTC）。旧记录缺少这些数据时显示“未记录”，不会用文件修改时间替代。

## 设置

设置页沿用 Obsidian 插件的分区顺序：LLM、arXiv 分类、研究主题、自动详细总结、输出与定时、个人文献库、邮件发送、高级、帮助。

- 修改后自动保存；关闭设置页会等待保存完成，失败时可以重试或放弃修改。
- 密钥类字段留空表示保留已保存的值，默认不回显。点击 **Show** 可以按需显示已保存的密钥，**Hide** 清除显示。
- **Get models** 会拉取并填充模型下拉列表，字段本身仍可自由输入和筛选。
- 有生成任务在运行时无法保存设置。
- “输出与定时”里还有一个进程内的定时器：**Enable** + **Check every (minutes)** 只在工作台进程保持运行期间按设定间隔检查日报（存成独立的 `workbench_schedule`，和你用 `schedule install` 装的外部 cron 任务互不影响）。

## 外观与界面语言

**设置 → 外观** 统一管理主题和界面语言（中/英），与生成报告使用的语言是两件事，互不影响。

## 个人文献库与方向审核

在**设置 → 个人文献库**连接并索引一个本地 PDF 目录，然后使用：

- **个人文献库** —— 按标题和摘要浏览/搜索已索引的论文，并在新标签页打开本地 PDF（最大 25 MiB）。
- **方向审核** —— 查看带代表性证据和预览的候选主题/方向，编辑它们，接受全部或部分。被接受的方向会变成普通的研究主题，参与日报筛选。当文献库里有此前分析未计入的新论文时，页面会提供更新入口，只把这些新论文发给模型。打开这两个页面本身不会调用模型。

终端里也可以用 `arxiv-daily library …` 做文献库搜索和索引，见 [CLI README](https://github.com/tdccccc/arxiv-daily/blob/main/apps/cli/README.zh-CN.md#可选的个人文献库)。

## 隐私说明

任何阅读或浏览操作都不会调用模型，也不会修改你的 Markdown 文件。只有明确的操作——生成报告、文献库索引/生成候选方向、拉取模型列表——才会发出网络/模型请求。
