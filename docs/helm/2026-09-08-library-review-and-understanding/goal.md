## Intent

落实 2026-09-08 产品评审：修复文献库方向复审中的数据丢失、证据兼容和过期覆盖问题，改善大库生成能力，并让用户容易找到、理解和验证文献库总结出的主题与方向。用户明确要求新开 Helm 并增加相应测试。

## Success criteria

- [x] 编辑方向后切换选择、改归属、刷新或保存失败均不静默丢失草稿；接受使用已审核的最新文字，保存失败不接受旧文本。
- [x] 非 arXiv 与混合来源方向可编辑文字、调整代表论文并保存；拒绝不属于已知证据的论文。
- [x] 已覆盖论文可追溯到生成时的方向；修改或删除该方向后不再宣称当前全部覆盖；支持检查覆盖依据。
- [x] 500 与 1000 篇有效库证据可在有界请求中完成组织；不靠只看摘要开头或静默丢论文满足上限；有容量与完整性回归。
- [x] 研究主题页提供文献库生成/复审入口，空状态能走完选库到接受方向。
- [x] 接受前能预览方向的论文匹配与原因，并核对独立的 arXiv 抓取分类；预览不修改现有订阅。
- [x] 文献库概览可持续浏览主题、方向、证据与未覆盖论文，代表论文可打开；零新增仍有可读结果。
- [x] 单领域、混合项目、非 arXiv 为主、少量新方向场景有可重复检查；相关测试、typecheck、边界检查与构建通过，并记录真实界面验收证据及未验证范围。

## Non-goals

- 自动接受方向、自动扩大抓取分类、恢复 reading candidates 或阅读反馈。
- 全文问答、引文图、personal novelty；不改变既有方向的一行文字筛选语义。
- 项目/时间范围与自动增量是上轮后续建议，等待本轮范围答复；不将其擅自视为已交付或永久取消。

## Constraints

- 保留当前 worktree 的全部既有未提交修改；不提交、不推送、不开 PR，沿用该 worktree 已有约束。
- 本 initiative 独立记录状态，不修改其他 active Helm 的 owner、状态或验收结论。
- 文献库概览与旧 discovery-loop Helm P5 的方向有关；这里实现具体产品结果，不冒充完成那个 initiative。
- 每个行为修改先观察有效 Red，再观察 Green；测试与实现同阶段验收。
- 不以结构化测试通过冒充模型语义质量或用户桌面确认；真实端点/桌面使用需遵循现有配置与授权范围。
