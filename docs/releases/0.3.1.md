## Overview

arXiv Daily 0.3.1 improves how papers are ranked for local discovery and how the pipeline decides which papers deserve standalone deep-dive notes. It also fixes detail-note deletion and strengthens Obsidian Community Directory compatibility while retaining support for Obsidian 1.4.0.

## Highlights

- Improves local Similar Papers ranking with abstract evidence, weighted concept coverage, multi-field bonuses, deterministic tie-breaking, and suppression of weak author-only matches.
- Separates daily topic inclusion from standalone deep-dive selection. After full-text extraction, one independent LLM review scores eligible papers for centrality, novelty, evidence strength, and long-term value.
- Adds Conservative, Balanced, Broad, and Custom deep-dive policies. Balanced remains the default, with a normal score threshold of 75, an exceptional threshold of 92, and a soft daily limit of three new detail notes.
- Fixes generated detail-note deletion for current `arxiv_id:` and legacy `arxiv:` metadata, rejects conflicting metadata, and immediately reconciles Dashboard and Paper Index state.
- Prevents failed detail generation from creating dangling daily-report links or false detail state.
- Adds abstract persistence and deterministic recovery of structured paper summaries from historical daily reports.

## Dashboard and reliability

- Similar Papers now shows topic/category, publication date, and available daily/detail resources, with unavailable actions disabled.
- Dashboard history invalidation tracks both daily reports and managed paper notes, so external paper-note creation, deletion, and rename operations are reflected without stale cache state.
- Existing canonical detail notes are detected and reconciled before automatic selection; they do not consume the daily soft limit.
- Detached Dashboard, command, and Settings actions now report failures instead of silently dropping rejected promises.
- API-key replacement and clearing restore the previous key and redaction state if settings persistence fails.

## Obsidian compatibility

- Minimum supported Obsidian version remains 1.4.0.
- Dashboard leaf activation and Settings help text no longer depend on APIs introduced after Obsidian 1.4.0.
- Detail deletion uses the user's configured trash behavior where `FileManager.trashFile` is available. On older supported Obsidian versions it uses the non-destructive legacy trash API, preferring system trash with Obsidian's local `.trash` fallback.
- URL opening, clipboard access, Dashboard controls, status panels, and timers now respect their owning Obsidian window, including pop-out windows.
- Custom Vault configuration directories are respected instead of assuming `.obsidian`.
- Official `eslint-plugin-obsidianmd` checks now run locally, on pull requests, and in release verification.

## Data compatibility

- The Paper Index schema is now version 3 and can persist an optional abstract.
- Existing Paper Index schema 1 and schema 2 files remain readable.
- Existing settings are migrated in place with the Balanced deep-dive policy as the default.
- Existing daily reports, detail notes, command IDs, and output paths remain compatible; no manual data migration is required.

## Security and privacy

- Similar Papers remains fully local and deterministic. It does not use embeddings, a vector database, an additional LLM call, or a network request.
- Automatic deep-dive selection adds one LLM scoring call after full-text extraction for eligible papers. Full-text candidate content is therefore sent to the configured LLM provider under the same privacy assumptions as summary generation.
- Saved plugin API keys remain plaintext in Obsidian's local plugin `data.json`; this release does not claim encrypted or keyring-backed storage.
- Generated-file deletion remains confined to validated canonical Vault paths and verifies matching generated metadata before moving a file to trash.
- The plugin does not send client-side telemetry.

## Install

Download these three assets and copy them directly to:

```text
<your-vault>/.obsidian/plugins/arxiv-daily/
```

- `manifest.json`
- `main.js`
- `styles.css`

Restart Obsidian, then enable **arXiv Daily** under **Settings → Community plugins**.

## Breaking changes

There are no data-format or command-ID breaking changes. Existing users can upgrade in place. As always, keep a Vault backup before upgrading community plugins.
