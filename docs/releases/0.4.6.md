# arXiv Daily 0.4.6

## Overview

This patch release improves the Research topics editing experience in Obsidian settings and cleans up the plugin's UI quality checks. Adding or removing a topic now keeps the settings context stable instead of forcing users to find their place again.

## Highlights

- **More stable topic editing** — Adding a topic reveals the new card immediately and focuses its Name field without an animated page jump. Deleting a topic preserves the neighboring topic's visual position, so the visible list does not unexpectedly shift.
- **Settings refresh continuity** — Settings list refreshes preserve the current scroll position for related controls, reducing jumpy behavior after list changes.
- **Cleaner plugin UI checks** — Plugin lint now runs without warnings. UI labels use consistent sentence case, and copy actions use the modern Clipboard API; when it is unavailable, the text is selected for manual copying.

## Install / upgrade

### CLI

```bash
npm install -g arxiv-daily@0.4.6
# or:
arxiv-daily update
```

### Obsidian plugin

Update through Obsidian's Community plugins interface after the matching GitHub release is available. The release assets remain exactly `manifest.json`, `main.js`, and `styles.css`.

## Compatibility

- **CLI package:** `arxiv-daily@0.4.6` after publication.
- **Node.js:** 20.19.0 or newer; Node.js 22 is also supported.
- **Obsidian minimum version:** unchanged at `1.4.0`.
- **Config format:** remains `schema_version = 1`.
- **Paper Index:** reads existing schemas 1–4 and writes schema 4; no manual migration is required.
- **Delivery state:** remains schema 1 for older-reader compatibility; private sidecars carry the stronger claim generation.
- **Existing configs, reports, paper notes, and valid indexes:** remain supported.
