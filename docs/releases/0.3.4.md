# arXiv Daily 0.3.4

## Overview

This release focuses on the **CLI product**: a guided TUI for first-time setup, clearer defaults, and documentation that matches how people actually install and run `arxiv-daily` from npm. The Obsidian plugin behavior is unchanged aside from shared version metadata.

## Highlights

- **Friendlier `arxiv-daily init`** — step-by-step TUI with explanations, defaults, and cancel/back navigation.
- **LLM setup order** — provider → base URL → API key → optional connection test / model list → model.
- **arXiv categories** — multi-select from the built-in category list (not only free-typed ids).
- **Official delivery setup** — optional verification email during init; paste the long web-page code.
- **Safer first-run defaults** — vault defaults to `~/arxiv-daily`; automatic paper notes default **off**.
- **English `config.toml` comments** — including `schema_version` at the **bottom** (do not edit unless a release note says so).

## Install / upgrade (CLI)

```bash
npm install -g arxiv-daily@0.3.4
# or upgrade
npm install -g arxiv-daily@latest

arxiv-daily help
arxiv-daily init          # if you are new, or re-run to overwrite/merge config
arxiv-daily run --today
```

Uninstall:

```bash
npm uninstall -g arxiv-daily
# config and vault data are NOT removed:
#   ~/.config/arxiv-daily/config.toml
#   your vault folder (e.g. ~/arxiv-daily)
```

## CLI: `init` wizard

### Navigation

| Key | Action |
|---|---|
| ↑ / ↓ | Move |
| Space | Multi-select (categories) |
| Enter | Confirm / keep default |
| **← Go back** (last menu item) | Previous step |
| **Ctrl+C** (or Esc in this TUI) | **Exit** the wizard |

Navigation help is shown once at the start so it does not clutter each input.

### Flow

1. **Vault path** — default `~/arxiv-daily` (expanded to an absolute path).  
2. **LLM provider** — DeepSeek, OpenAI, Anthropic, Zhipu, Custom, …  
3. **API base URL** — filled from the provider preset; **Custom leaves URL empty** for you to enter.  
4. **API key** — stored in the config file (plaintext; do not commit the file).  
5. **Test connection / load models** — optional; uses the provider `/models` API when available.  
6. **Model** — from the remote list, preset list, or typed id.  
7. **Email** — skip / Send yourself (Resend) / Official delivery (Beta, optional verify email + token).  
8. **arXiv categories** — multi-select.  
9. **Timezone** and **summary language**.  
10. **Topic** — name, tag, description (placeholder is fine to edit later).  
11. **Optional** — auto paper notes (default **No**); optional schedule intent for `schedule install`.

Not prompted (always written as defaults): `link_style = "wikilink"`, `log_level = "info"`.

### Config file

- Path: `$XDG_CONFIG_HOME/arxiv-daily/config.toml` (default `~/.config/arxiv-daily/config.toml`; Windows `%APPDATA%\arxiv-daily\config.toml`).  
- Comments are **English**.  
- **`schema_version = 1`** is at the **end** of the file for future migrations — leave it alone unless a release note says otherwise.

## CLI commands (unchanged surface)

```text
arxiv-daily init
arxiv-daily run --today
arxiv-daily run --date YYYY-MM-DD
arxiv-daily run --id ARXIV_ID [--date YYYY-MM-DD]
arxiv-daily email test|status|verify-start
arxiv-daily schedule show|install|uninstall
arxiv-daily data export --out PATH.zip
arxiv-daily data import PATH.zip [--yes]
arxiv-daily help
```

- There is **no** multi-day `run-pending`; cron should call `run --today`. Missed days: `run --date …`.  
- Windows: use **WSL** for `schedule install`, or the Obsidian plugin for desktop scheduling.

## Compatibility

- **Plugin:** no intentional behavior change; version bumped with the workspace.  
- **CLI config:** still format `schema_version = 1`. Existing 0.3.3 configs keep working.  
- **npm package name:** `arxiv-daily` (global bin `arxiv-daily`).  
- Re-run `init` only if you want a new guided setup; otherwise edit `config.toml` by hand.

## Upgrade notes from 0.3.3

1. `npm install -g arxiv-daily@0.3.4`  
2. Keep your existing `config.toml` unless you prefer a fresh `init`.  
3. If you never set topic `detail`, automatic paper notes remain off unless you enable them.  
4. Optional: `arxiv-daily schedule install` after setting `[schedule] enabled = true`.
