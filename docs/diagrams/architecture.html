arXiv Daily 每天拉取 arXiv 新论文，按研究者自己写的研究主题和方向筛选，生成本地 Markdown 日报和论文总结。可以选择接入个人 PDF 文献库，由模型提议新的研究方向，研究者确认后才影响每日筛选。

系统全景

所有业务逻辑都在 @arxiv-daily/core 里。Obsidian 插件和 Node 是两个“宿主”，各自把网络、磁盘、密钥等能力注入业务核。工作台、DSH 插件和 VS Code 扩展不重写生成逻辑，而是启动 CLI 进程来跑。

图 2

每日流水线

按日期运行，每天一次。阶段之间有 checkpoint，中断后重跑不会重复已经完成的模型调用。只有完整日报写入并确认运行状态后，这一天才算完成。

图 3

个人文献库如何变成研究方向

文献库是可选的，而且不直接影响日报。模型只负责提议；研究者接受的方向会以普通文本写进研究主题，之后与手写的方向没有区别。

邮件投递与依赖边界

邮件宁可漏发也不重发。代码依赖只能单向流向业务核，CI 里的边界脚本会拦下反向依赖。
